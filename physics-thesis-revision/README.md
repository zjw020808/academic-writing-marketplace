# physics-thesis-revision

理论物理与量子信息方向中文学位论文的改稿插件，包含三个技能：

| 技能 | 解决的问题 |
|---|---|
| `section-logic-revision` | 段落主旨不清、段与段之间没有承接、相邻句各说各的 |
| `abstract-introduction` | 摘要东拉西扯、第一章背景堆砌、缺口不出现、结果只报形式 |
| `claim-evidence-review` | 某句断言有没有依据、范围是否写宽、术语与数值是否一致 |

## 适适配范围

- 中文学位论文，理论物理/量子信息方向。
- 以定义、引理、定理、证明、原文引用和可复算数值为主要证据。
- 默认对象是子系统量子 Fisher 信息与纠缠判据这类题目；其他理论物理题目可直接换例子。

## 方法来源

段落主旨、编码—诊断—改链—解码、反向提纲、句子衔接检查等思路，参考彭思达公开的科研写作方法论。本插件为原创改写：规则、检查表和全部例子按理论物理论文重写，不包含上游仓库的文字或示例。上游仓库未提供许可证，因此这里不复制其内容。

## 安装

本插件由 `academic-writing-marketplace` 市场提供。把市场仓库添加到 Claude Desktop 后，在插件列表里安装 `physics-thesis-revision`。

## 与项目规程的关系

三个技能只提供诊断与候选改写，不替代作者判断，也不改变论文项目的确认流程。涉及公式、数值、引用键、术语首现和范围的改动，一律单列待作者确认。
