# 摘要与第一章绪论的结构

## 先定 story，再写摘要

写摘要前，先用四句话回答：

1. 本文解决什么问题？一句话，含对象与限定。
2. 已有工作缺什么？一句话，含技术原因，不是“研究较少”。
3. 本文做了什么？一句话，方法名加关键动作。
4. 得到了什么？三到四条结果，每条写“变化”，不写“形式”。

四句话定不下来，先不要写摘要。摘要是全文的压缩；第一章的论证链没立住，摘要一定返工。

## 摘要：五步主线

1. **问题**：这个量或判据为什么值得研究。给读者理解问题所需的最小背景。
2. **缺口**：已有判据在什么条件下不够用，技术原因是什么。
3. **做法**：本文用什么表示、什么上界、什么测量条件；只给关键术语，不展开步骤。
4. **结果**：三到四条，按“收紧—优化—阈值或边界—时间参量”之类的顺序排；每条写“从什么变成什么”或“在什么范围内成立”。
5. **意义**：只写证据支持的范围；不写“首次”“国际领先”“广泛应用”。

写作要求：

- 1,000～1,250 字，3～4 段；结果段另起一段。
- 术语首现给中文名；已有理论术语给英文，自引入术语不硬造英文。
- 不列公式、不写章节号、不写“然后证明”“最后证明”这类过程自述。
- 每段第一句点明这段的任务。

## 第一章绪论：四节的分工

### 1.1 背景与意义

按“测量精度—QFI—纠缠判据”三步推进。每一步只给下一步需要的背景；不要把量子信息史、计量史、纠缠史各写一遍。

每段结束时，给下一段留一个明确的缺口。

### 1.2 研究现状

按一条轴组织，不要按作者罗列。以“判据左端用什么量”为轴时，可以这样排：

整体 QFI 判据 → 集体自旋或自旋压缩判据 → 只测子系统的判据 → 现有工作的缺口。

比较段必须给比较对象、比较量、比较范围。

### 1.3 本文主要内容和创新点

它是摘要的扩展，不是目录的展开。

- 先总述问题与回答。
- 再按三条内容线写：判据建立、收紧与优化、时间参量。
- 每条写“做了什么—得到什么—边界在哪”。
- 不后指“第三章 3.1 节”“第四章 4.1 节”。

### 1.4 论文结构安排

六句以内，每章一句，只写章的功能，不写结论。

## 段落职责表

写之前先填，写完再核对：

| 段号 | 本段任务 | 让读者接受什么 | 与上段的承接 | 证据或出处 |
|---|---|---|---|---|

填不出的格子，就是需要补或删的地方。

## 常见病与改法

- **背景堆砌**：删掉与本文问题无关的历史；每段背景都要能回答“没有它，读者会误解哪一步”。
- **缺口不出现**：在 1.2 末明确写“现有判据在只测子系统时缺什么”，不要用“仍有研究空间”。
- **方法先行**：先给问题与缺口，再给方法名；不要让读者在不知道为什么要做时先读步骤。
- **结果只报形式**：把“给出了解析形式”改成“在 d=2 时阈值由……降到……”。
- **术语跳变**：同一对象全程一个名字；首现位置按 `sqfi-thesis-writing` 的术语表。

## 输出格式

1. story 四句话。
2. 摘要候选，分段，每段前标任务。
3. 绪论段落职责表。
4. 待作者确认项：事实、术语、数值、范围。

## 边界

- 不补造结果、不引用未核文献、不把导师的示例措辞当定稿。
- 不写“创新点”之外的自我评价。
- 输出为候选，须按项目规则逐项确认。
