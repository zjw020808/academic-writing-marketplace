# thesis-night-run

中文学位论文的夜间批处理与人工介入分级插件，包含一个技能：

| 技能 | 解决的问题 |
|---|---|
| `task-triage-night-run` | 哪些任务我自己做，哪些可以夜里自动跑；跑完早上看什么 |

## 三档

- **T1 可自动**：只读核查、批注提取、术语/引用/符号一致性检查、脚本复算、编译与格式检查、把段落压成主旨表。产出是报告，不改正文。
- **T2 可自动但需复核**：整段候选改写、章节结构方案、摘要候选、多方案对照。产出是候选稿，必须标“候选”。
- **Gated 必须等人**：术语取舍、章节结构、创新点表述、数值/范围/因果主张、导师意见取舍，以及任何写入正式稿、任务书、术语表、决策记录的动作。

## 夜间执行边界

只读 `01`～`05`；只写 `06_讨论与确认/夜间批处理_日期/`；不碰 `07_新论文工作区` 与 `08_交付`；不改已确认正文、术语表、任务书、决策记录；不删除文件、不覆盖原稿、不运行旧脚本。

## 与项目规则的关系

分级是建议，不是批准。Gated 项不因为被列进清单就算确认；所有产出都是候选，须作者逐条核对。项目原有的逐步确认规则不因本插件而改变。

## 配套

与 `physics-thesis-revision` 配合使用：前者决定“哪些能做”，后者负责“具体怎么改”。
